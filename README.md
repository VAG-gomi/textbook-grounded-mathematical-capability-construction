# Higher Mathematics Orders

A textbook-grounded progression of minimal deterministic artificial mechanisms, moving from scalar measurement to persistent selected-rule inference.

This is a historical research repository, not a neural-network implementation or a claim of general intelligence.

## Orders

The historical build covers Orders 1–8: scalar measurement, persistent state, formal determination-controlled branching, causal history, rule-state modification, evaluation-driven correction, addressable finite relations, finite graph representation, and selected affine-rule inference.

Order 3 is preserved as a formal control-flow milestone but is documented as behaviorally degenerate with Order 2 under exact equality.
